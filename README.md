# Color Palette Generator

A simple and interactive **Color Palette Generator** built with **HTML, CSS, and JavaScript (ES6 Modules)**. Generate random color palettes, copy color codes instantly, and save your favorite palettes using **LocalStorage**.

## Features

* Generate **5 random colors**
* Copy HEX color codes to clipboard
* Toast notification after copying a color
* Save the current palette to **LocalStorage**
* Modular JavaScript structure using **ES6 Modules**
* Responsive and clean UI

## How It Works

1. Click **Generate Palette** to create a new set of random colors.
2. Click the **clipboard icon** to copy any color code.
3. Click **Save Palette** to store the current palette in LocalStorage.
4. Toast notifications provide instant feedback for user actions.
